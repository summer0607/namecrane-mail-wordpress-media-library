# 游先锋图库

将图片、视频、音频和文件上传到用户自己的游先锋邮箱网盘，自动生成公开链接。

启用“替换媒体库”后，WordPress 与子比主题的媒体选择入口会直接打开游先锋图库；作者和编辑只能查看、插入与删除自己上传的媒体，并可通过“登录”保存自己的游先锋邮箱账号。

“上传图片”页面提供顺序上传队列：可一次选择多张图片、在上传期间继续加入图片，并按图片内容去重，重复点击不会重复上传同一张图片。

文章编辑器、子比主题及其他已接管的“上传”“添加图像”入口均使用同一个图库弹窗：可多选图片、查看上传队列；完成上传后会在弹窗下方显示缩略图，点击缩略图即可直接写入当前字段或文章。

管理员可在“游先锋图库 → 管理图片”查看所有用户的图片，支持多选后批量删除；删除会先移除对应用户游先锋邮箱网盘中的原文件，再清除图库记录和虚拟媒体记录。

## 更新方式

管理员在“游先锋图库 → 设置”中填写仅对本仓库具有 **Contents 读取**权限的 GitHub Fine-grained Token。之后可在 WordPress 的“插件”列表点击“检查更新”，发现新版本后使用原生“立即更新”按钮升级。

用户的游先锋邮箱账号和密码只保存在各自的 WordPress 用户资料中，不会写入本仓库。
